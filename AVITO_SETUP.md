# Настройка интеграции с API Avito

## 🎯 Полученные ключи

У вас есть следующие ключи для интеграции с Avito:

### Интеграция с сайтом (используем эти)
- **Client ID**: `<ваш_client_id>` (задаётся через env `VITE_AVITO_CLIENT_ID`)
- **Client Secret**: `<ваш_client_secret>` — **НЕ коммитить!** Хранить в `.env.local` / Secrets CI / VPS
- **Redirect URL**: `https://bestmac.ru`

> ⚠️ **Безопасность:** реальные значения ключей запрещено хранить в git. Они
> задаются только через переменные окружения (`.env.local`, Replit Secrets,
> секреты CI/VPS). `.env.local` уже в `.gitignore`.

## 🚀 Настройка

### Шаг 1: Файл переменных окружения

Файл `.env.local` уже создан с правильными настройками для Vite:

```bash
# Avito API Configuration
VITE_AVITO_CLIENT_ID=<ваш_client_id>
VITE_AVITO_CLIENT_SECRET=<ваш_client_secret>
VITE_AVITO_REDIRECT_URL=https://bestmac.ru

# Другие настройки
VITE_SITE_URL=http://localhost:3000
```

**Важно**: В Vite используются переменные с префиксом `VITE_` вместо `REACT_APP_`

### Шаг 2: Настройка Redirect URL в Avito

1. Перейдите в [личный кабинет разработчика Avito](https://developers.avito.ru/)
2. Найдите ваше приложение "Интеграция с сайтом"
3. Убедитесь, что Redirect URL установлен как: `https://bestmac.ru`

### Шаг 3: Тестирование

1. Запустите проект: `npm run dev`
2. Откройте [http://localhost:8080/](http://localhost:8080/)
3. В разделе "Подключение к Avito" нажмите "Подключить к Avito"
4. Выполните авторизацию через Avito
5. После успешной авторизации ваши объявления появятся в разделе "Актуальные предложения"

## 🔐 Как работает OAuth2 авторизация

1. **Инициация**: Пользователь нажимает "Подключить к Avito"
2. **Перенаправление**: Браузер переходит на страницу авторизации Avito
3. **Авторизация**: Пользователь вводит логин/пароль Avito
4. **Callback**: Avito перенаправляет обратно с кодом авторизации
5. **Обмен токена**: Сайт обменивает код на access token
6. **API вызовы**: Используя токен, сайт загружает объявления

- Автоматическое обновление при истечении срока
- Возможность отключения интеграции
- Fallback на тестовые данные при ошибках

## 🔧 Возможные проблемы

### Ошибка "Invalid redirect_uri"
- Проверьте, что Redirect URL в Avito точно совпадает с `VITE_AVITO_REDIRECT_URL`

### Ошибка авторизации
- Убедитесь, что Client ID и Client Secret указаны правильно
- Проверьте, что приложение активно в личном кабинете Avito

### Токен не сохраняется
- Проверьте, что localStorage доступен в браузере
- Попробуйте очистить кэш браузера

### Ошибка "process is not defined"
- Убедитесь, что используются переменные с префиксом `VITE_`
- Перезапустите проект после изменения `.env.local`
