## 3. Что сделать владельцу (15–30 минут)

1. **Влить PR #37, #38, #39, затем #40** — каждый проверен тестами, сборкой и независимым ревью.
2. **Завести цели в Метрике** (Настройки → Цели → JavaScript-событие), по одной
   на идентификатор: `lead_form_submit`, `photo_estimate_done`, `tg_cta_click`,
   `click_telegram`, `click_phone`, `click_whatsapp`, `click_email`. Без этого рост заявок не виден.
3. **Проверить ключ RuCaptcha в секретах GitHub.** Плановые прогоны парсера
   19–22.09 собрали 0 объявлений с `ERROR_ZERO_BALANCE`. Сейчас цены держатся
   за счёт синка коллектора (90 из 201 конфигурации свежие за 7 дней), но без
   парсера Mac Studio и часть MacBook устаревают.
4. **Выкатить бота на VPS:** `cd /opt/bestmac && git pull && sudo systemctl restart bestmac-bot.service`.
5. **После каждой сделки** — `/review` в боте и переслать клиенту (см. раздел 5).

~10 000 ₽. При конверсии сайта в заявку 5% и заявки в сделку 20% окупается

проверить Прогнозом бюджета]. Кейсы ниши: скупка айфонов — заявка 3 000 →
800 ₽ за 4 месяца после калькулятора на сайте [Ф, vc.ru]; магазин Apple —
~1 500 ₽ за заявку [Ф, vc.ru].

**Почему не сейчас.** Нечем измерить результат (нет целей), и нет

будет конвертироваться хуже. Деньги уйдут без вывода.

**Условия старта:** цели в Метрике заведены и собирают данные 2+ недели;

## 6. Продукт для перекупщиков: узкая закрытая бета, не массовый сервис

**Рынок [Ф]:** мгновенные уведомления уже продают Avtoringer (550–2 750 ₽/мес),
Scanurik (заявляет 10 000+ пользователей), MULTISCAN, Speculator. По скорости
с ними не спорить. Но никто не сравнивает цену объявления с рыночной
медианой конфигурации — это наш уникальный актив.

**Риски [Ф/О]:** п. 2.4 соглашения Авито запрещает ботов; перепродажа
выгрузки базы — риск претензии (ст. 1334 ГК), сигналы со ссылкой — ниже;
блокировки и рост расходов на капчу; каждый сигнал подписчику — возможная
упущенная сделка BestMac.

**Предложение [О]:**
- **Продукт — аналитика, а не скорость:** «объявление на N% ниже медианы по M
  объявлениям, типичный срок продажи».
- **Тарифы:** 990 ₽/мес (5 подписок «модель + макс. цена», проверка раз в
  5–10 минут) и 1 990 ₽/мес (20 подписок + еженедельный отчёт по медианам).
- **MVP, 4–6 недель:** Telegram-бот на существующих подписках
  (`scripts/common/subscriptions.py`), сигнал «ниже медианы на ≥X%», оплата
  через ЮKassa, закрытая бета 20–30 человек.
- **Защита своих сделок:** модели, которые BestMac активно выкупает, —
  с задержкой 30–60 минут.
- **Критерий go/no-go после беты:** 15+ платящих, отток < 30% в месяц,
  капча и прокси < 25% выручки.

**Решение за владельцем.** Код не писал: нужны юридическая позиция и
готовность делиться сигналами с конкурентами по закупке.
